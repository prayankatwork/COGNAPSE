# COGNAPSE — Copy & Voice

## Tone

Serious, exact, cinematic. An intelligence command center—not a chatbot toy or social app.

## Preferred terms

| Use | Instead of |
|-----|------------|
| Research | Post, content |
| Analysis / synthesis | Magic answers |
| Archive / dossier | Feed |
| Source / verify | Trust this AI |
| Authorized analyst | User |
| Protocol / secure vault | Account stuff |
| Shared research (read-only) | Public post |
| Intelligence vector | Category tag (UI may say “subscriptions”) |
| Activate premium | Buy now (in product UI) |

## Micro-label style

- Uppercase, 9–10px, wide tracking: `RESEARCH PROTOCOL`, `LAST SYNC`, `SECURE ARCHIVE`
- Serif italic for titles: report names, hero lines
- Avoid exclamation marks except rare success moments

## Empty states

State what is missing and one clear action. No jokes.

> No intelligence vectors active. Subscribe to categories to begin global forensic monitoring.

## Errors

Operational, not apologetic.

> Session expired. Sign out and sign in again, then retry payment.

## Removed product language (do not use)

Boards, collaborators, forks, likes, followers, viral, community feed—unless those features return.
